# 🎓 Tuition Mafia — Modern Creative Education Syndicate

An ultra-modern, cinematic, scroll-animated website for **Tuition Mafia** built using **React.js**, **GSAP**, and **Tailwind CSS**. Designed for forward-thinking modern students who refuse outdated rote learning and want to master concepts creatively with unfair competitive advantages.

> **Motto:** *Learn Smart. Grow Big.*

---

## 🌟 The 4 Core Brand Pillars

- **🎓 EXPERT GUIDANCE:** Direct mentorship from Olympiad medalists, IIT/NIT top rankers, and passionate creative educators.
- **💡 INTERACTIVE LEARNING:** Abstract equations transformed into intuitive visual 3D models and real-world simulations.
- **📈 BETTER RESULTS:** Proven 99.4% top-tier percentile achievements across board and competitive examinations.
- **🏆 SUCCESS IN LIFE:** Developing critical thinking, strategic resilience, and creative mastery for university and beyond.

---

## 🚀 Key Website Features

- ⚡ **GSAP ScrollTrigger Mask Zoom:** Dramatic hero typography SVG mask zoom revealing the Tuition Mafia brand ethos.
- 🎞️ **Cinematic Video Scrubbing:** Interactive scroll-driven video reels demonstrating visual problem solving in action.
- 🎯 **Modern Scholar Parallax Showcase:** Asymmetric staggered parallax cards exploring the creative pedagogy.
- 👨‍🏫 **The Syndicate Masterminds:** Highlight reel of top 1% faculty mentors with live doubt warfare analytics.
- 🔴 **Live Interactive Studio:** HUD viewfinder frame showcasing live masterclasses with 1-on-1 booking CTA.
- 📝 **Interactive Syndicate Trial Modal:** Multi-field diagnostic test and masterclass booking form with responsive validation.
- 📱 **Adaptive Navigation Drawer:** Fixed glassmorphism header with mobile off-canvas menu and instant admissions hotline.

---

## 🛠️ Tech Stack

- **React 19** – UI library
- **GSAP & ScrollTrigger** – High-performance scroll-driven timelines & vector masking
- **Tailwind CSS 4** – Utility-first responsive design
- **Vite** – Ultra-fast development & production bundling

---

## 💻 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
